# Sintia_Juniarti_Pemograman-Mobile-

Menambahkan aplikasi Flutter sederhana menggunakan StatelessWidget.

Aplikasi menampilkan:
- MaterialApp sebagai root aplikasi
- Scaffold dengan AppBar berwarna deepOrange
- Column untuk menyusun teks secara vertikal
- 9 Text widget yang menampilkan pesan dengan string interpolation

Menggunakan mainAxisAlignment dan crossAxisAlignment untuk mengatur posisi teks.
